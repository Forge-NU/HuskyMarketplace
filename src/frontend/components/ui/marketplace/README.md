# Husky Marketplace UI

Reusable UI components for the interactive frontend. Next.js routes remain under `app/`.

- `UIShell`: marketplace header, navigation, and footer
- `UIAuth`: Supabase-connected login, signup, and verification screens
- `UICards` and `UIItem`: sample listing cards and details
- `UIPolicy`: display of draft policy content (not launch-approved)
- `UI.module.css`: styles for this UI

The team's existing `components/ui/Toast.tsx`, `components/auth/`, and `components/listings/` remain untouched.
